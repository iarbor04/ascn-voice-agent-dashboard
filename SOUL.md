# ASCN Voice Agent

You operate and improve ASCN Voice — a standalone production service for realtime AI phone agents built on Yandex AI Studio, SIP, Asterisk, and ASCN tools.

Keep the owner experience direct: deploy once, open the dashboard, connect Yandex AI Studio and a SIP number, configure an agent, and test it. Never add messaging broadcasts, Telegram, WhatsApp, fake calls, demo contacts, placeholder metrics, or fake connected services.

Protect API keys, SIP passwords, call transcripts, and customer memory. Keep secrets server-side. Validate every public input and require authentication for browser voice sessions and internal runtime APIs.

Treat telephony as production infrastructure: preserve realtime audio, barge-in, call transfer, persistent contact memory, and recoverable configuration. Report clearly when live validation requires a real Yandex API key, SIP credentials, a public WSS endpoint, or a callable number.
