# ASCN Voice — исходящий звонок

Звонок делает голосовой агент из панели ASCN Voice через собственный SIP-номер. Звонок реальный: человек на другом конце снимет трубку.

## Настройка (один раз)

```bash
export ASCN_VOICE_URL="http://localhost:3000"
export ASCN_INTERNAL_KEY="<INTERNAL_API_KEY из .env панели>"
```

Ключ — тот же `INTERNAL_API_KEY`, которым шлюз ходит в панель. Он даёт право инициировать звонки, поэтому храни его как пароль.

## Шаг 1. Разобрать запрос

Из просьбы пользователя собери три вещи:

1. `caller_name` — кому звоним: название компании или имя человека.
2. `caller_purpose` — что нужно сделать. Подробно, разговорным языком, со всеми деталями (даты, суммы, адреса, номера заказов). Агент сам разобьёт это на реплики — не пиши сценарий.
3. `toNumber` — номер в формате `+7XXXXXXXXXX`.

## Шаг 2. Найти номер, если его не дали

- **Человек по имени** → сначала ищи в Контактах macOS:

```bash
osascript -e 'tell application "Contacts"
set out to ""
repeat with p in (people whose name contains "ИМЯ")
set out to out & (name of p) & " || "
repeat with ph in phones of p
set out to out & (value of ph) & " ; "
end repeat
set out to out & linefeed
end repeat
return out
end tell'
```

Ровно одно совпадение — используй его. Совпадений нет, их несколько или имя не то — **остановись и спроси**. Никогда не звони на угаданный номер.

- **Компания** → найди публичный номер поиском в интернете и покажи источник.

## Шаг 3. Подтвердить у пользователя

Перед набором покажи одной строкой: кому звоним, на какой номер, с какой задачей, каким агентом. Дождись явного «да». Звонок нельзя отменить после снятия трубки, а на другом конце живой человек — это не тот случай, где можно действовать по умолчанию.

## Шаг 4. Позвонить

```bash
curl -s -X POST "$ASCN_VOICE_URL/api/voice/calls" \
  -H "authorization: Bearer $ASCN_INTERNAL_KEY" \
  -H "content-type: application/json" \
  -d '{
    "toNumber": "+7XXXXXXXXXX",
    "variables": {
      "caller_name": "<КОМУ>",
      "caller_purpose": "<ЧТО НУЖНО СДЕЛАТЬ>"
    }
  }'
```

Необязательные поля: `agentId` — конкретный агент (по умолчанию активный), `connectionId` — с какого номера звонить, если их несколько.

В ответе придёт `call.id`. Сообщи пользователю, что агент набирает.

## Шаг 5. Следить за звонком

```bash
curl -s "$ASCN_VOICE_URL/api/voice/calls/<call_id>" \
  -H "authorization: Bearer $ASCN_INTERNAL_KEY"
```

Статусы: `queued` → `dialing` → `live` → `ended` (или `failed` с текстом в `error`). Опрашивай раз в 10–15 секунд, пока не `ended`.

В ответе:
- `messages` — расшифровка диалога в реальном времени;
- `call.outcome` — появляется после завершения: `resolved`, `summary`, `confirmation` (номер заявки), `operator` (имя сотрудника), `nextStep`.

## Шаг 6. Отчитаться

Скажи, чем закончилось, назови номер подтверждения и имя сотрудника, если они есть. Если `resolved: false` — объясни, на чём застряло, и предложи следующий шаг.

## Что нужно на стороне панели

- у агента включён инструмент **Тональный набор (IVR)** — иначе он не пройдёт автоответчик;
- промпт агента заполнен по шаблону «Личный ассистент (IVR)» с переменными `{{caller_name}}` и `{{caller_purpose}}`;
- в «Подключение и номера» настроен SIP-номер с форматом набора под оператора;
- заполнено поле «Живой оператор», если нужен перевод звонка на человека.

## Ограничения

- Массовый исходящий обзвон запрещён офертой почти всех российских операторов — номер заблокируют. Скилл рассчитан на единичные поручения.
- Один SIP-канал = один звонок за раз. Параллельные звонки требуют нескольких каналов у оператора.
